물질 변화 개념 암기 테스트

과학 Ⅰ. 화학 반응의 규칙과 에너지 변화 · 20문항

태은아, 시작 전에 개념부터 한 번!

아래 개념 카드를 눌러서 쭉 읽고 시작하면 훨씬 잘 풀려요. 다 풀고 나서 다시 읽으면 암기가 확실해집니다.

  • 물리 변화 = 물질의 성질은 그대로, 모양이나 상태만 변하는 현상
    → 분자의 배열만 변한다
  • 화학 변화 = 어떤 물질이 성질이 다른 물질로 변하는 현상
    → 원자 사이 결합이 끊어지고 새 결합이 생겨 원자의 배열이 변한다 → 분자의 종류가 달라진다
물리 변화 — 변하는 것분자의 배열
물리 변화 — 안 변하는 것분자의 종류와 개수, 물질의 성질, 원자의 배열, 원자의 종류와 개수
화학 변화 — 변하는 것분자의 종류와 개수, 물질의 성질, 원자의 배열
화학 변화 — 안 변하는 것원자의 종류와 개수 (이건 어떤 변화에서도 안 변함!)
  • 물리 변화 예 — 모양(컵이 깨짐, 종이 오림, 캔 찌그러뜨림) / 상태(아이스크림 녹음=융해, 유리창에 김 서림=액화) / 용해(설탕이 물에 녹음) / 확산(향수 냄새, 잉크 퍼짐)
  • 화학 변화 예 — ①빛과 열 발생(나무·양초가 탄다) ②색·냄새·맛 변화(철이 녹슴, 깎은 사과 색 변함, 김치가 시어짐, 음식물 부패, 단풍) ③앙금 생성(석회수+이산화 탄소 → 뿌옇게) ④기체 발생(상처에 과산화 수소수 → 거품)
  • 원자 = 물질을 구성하는 기본 입자 / 분자 = 물질의 성질을 나타내는 가장 작은 입자(원자들이 결합해 이루어짐)
  • 양초: 녹고(융해) 기화하는 것 = 물리 변화 / 심지가 타며 빛과 열을 내는 것 = 화학 변화
  • 화학 반응 = 화학 변화가 일어나는 과정 / 반응물 = 반응에 참여하는 물질 / 생성물 = 반응 후 만들어진 새 물질
  • 화학식 = 물질을 이루는 원자의 종류와 수를 원소 기호로 나타낸 식
  • 화학 반응식 = 화학식을 이용해 화학 반응을 나타낸 식
1단계화살표 왼쪽=반응물, 오른쪽=생성물. 두 가지 이상이면 '+'로 연결
수소 + 산소 → 물
2단계화학식으로 나타내기   H2 + O2 → H2O
3단계반응 전후 원자의 종류와 개수가 같도록 계수를 맞춤. 계수는 간단한 정수, 1이면 생략
2H2 + O2 → 2H2O
  • 반응식으로 알 수 있는 것: 반응물·생성물의 종류, 원자의 종류와 개수, 계수비(=분자 수의 비)
    메테인 연소 CH4 + 2O2 → CO2 + 2H2O  → 계수비 1 : 2 : 1 : 2
  • 반응의 종류 — 화합 A+B→AB / 분해 AB→A+B / 치환 AB+C→A+CB (예: 질산 은 + 구리 → 은 + 질산 구리(Ⅱ))
  • 화학식 암기: 산소 O2, 수소 H2, 질소 N2, 물 H2O, 과산화 수소 H2O2, 메테인 CH4, 암모니아 NH3, 이산화 탄소 CO2, 탄소 C, 산화 구리 CuO

객관식은 정답을 고르면 자동으로 다음 문제로 넘어가고, 틀리면 해설을 보고 직접 넘어가요. 언제든 이전 버튼으로 돌아가 답을 고칠 수 있어요.
