- R1 questions (5개, 순서 고정):

  3. mc "내용 일치" 또는 "내용 불일치" (prompt도 그에 맞게).
  4. write "요약문 완성" — box 안 요약문에 `(A) [[blank]]`, `(B) [[blank]]` (철자 힌트를 줄 때는 `(A) o[[blank]]` 형식). 조건을 prompt에 명시. answer는 "(A) ...  (B) ...".
  5. write "배열 영작" — box 우리말, bank는 " / " 구분 단어(섞어서), lead는 첫 단어(선택). answer 완성문.
- R2 questions (4개, 순서 고정): mc "빈칸 추론"(영어 선택지) / mc "어법"(choices ["①","②","③","④","⑤"]) / write "어법 고쳐 쓰기" / write "내용 서술"(우리말 N자 내외) 또는 "조건 영작".
