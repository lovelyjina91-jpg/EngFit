## 저작권 (가장 중요)
- 모든 영어 지문·문제·선택지·해설·한국어 문장은 100% 새로 창작. 시판 교재·기출 문장을 옮기거나 살짝 바꿔 쓰지 않는다.
- 실존 캐릭터·브랜드(디즈니, 포켓몬, 해리포터, 특정 기업 제품명) 금지.
- 아래 소재는 쓰지 않는다(다른 책이 이미 씀): 시험 압박/자기 의심, 오감, 거짓말의 진화, 걸어서 생긴 길, 표정, 광고, 첫 10분 규칙, 접시, 이름, 번역, 근육, 고래, 깨끗함, 발명가, 기억 떠올리기, 스포트라이트 효과, 자이가르닉 효과.

## 대상·난이도
- 중3~고1. 고1 학력평가 쉬운 지문 수준. 자연스러운 미국식 영어, 문법 오류 0.
- 사실 정보는 **확실한 것만**. 정확한 수치·연도가 애매하면 쓰지 말고 일반적 서술("many", "in one study")로. 과장 금지.

## 분량 (쪽 넘침 방지 — 꼭 지킬 것)
- READING 1: 3문단(도입/전개/결론), **210~235단어**. glossary 8개(영영 뜻, 짧게).
- READING 2: 3문단(도입/전개/결론), **155~180단어**. glossary 6개.
  - R2 지문에 `[[BLANK]]` 정확히 1개(빈칸 추론용), `{1:word}`~`{5:word}` 번호 밑줄 정확히 5개(어법용, 그중 정확히 1개만 틀리게). 번호는 등장 순서대로 1→5.
- R1 굵은 핵심 구문 `**...**` 2개, R2 굵은 구문 1~2개.
- R1 결론 또는 전개에 함의 추론용 `__...__` 밑줄 구절 1개 (6~16단어).
- 선택지 영어는 한 줄(약 12단어 이내), 한국어 선택지는 35자 이내.

## 문제 구성 (고정)
- R1 questions (5개, 순서 고정):
  1. mc 대의 — kind는 "요지"/"주제"/"제목"/"주장" 중 하나(단원마다 바꿔 가며). 요지·주장은 한국어 선택지, 주제·제목은 영어 선택지.
  2. mc "함의 추론" — box에 밑줄 구절 그대로.
  3. mc "내용 일치" 또는 "내용 불일치" (prompt도 그에 맞게).
  4. write "요약문 완성" — box 안 요약문에 `(A) [[blank]]`, `(B) [[blank]]` (철자 힌트를 줄 때는 `(A) o[[blank]]` 형식). 조건을 prompt에 명시. answer는 "(A) ...  (B) ...".
  5. write "배열 영작" — box 우리말, bank는 " / " 구분 단어(섞어서), lead는 첫 단어(선택). answer 완성문.
- R2 questions (4개, 순서 고정): mc "빈칸 추론"(영어 선택지) / mc "어법"(choices ["①","②","③","④","⑤"]) / write "어법 고쳐 쓰기" / write "내용 서술"(우리말 N자 내외) 또는 "조건 영작".
- 객관식 answer는 1~5 정수. **정답 위치는 아래 배정표를 그대로 따를 것** [R1Q1, R1Q2, R1Q3, R2Q1, R2Q2]. R2Q2(어법)의 정답 번호 = 틀린 밑줄 번호.
- 모든 mc에 why(정답 근거, 지문 문장 인용)와 wrong(정답 외 4개 각각 왜 아닌지)을 쓴다. 정답은 하나만, 확실하게.
- R2에 "blank_answer" 키 = 빈칸 정답 선택지 문자열.
